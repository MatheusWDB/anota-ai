# Sobre o projeto  
**Anota Aí** é um aplicativo mobile simples e prático para controle de despesas pessoais. Desenvolvido como uma aplicação full stack, ele permite ao usuário registrar, editar, filtrar, ordenar e apagar suas despesas de forma intuitiva. O projeto também inclui funcionalidades de cadastro, login e atualização de perfil com foto.

## Funcionalidades:
- Cadastro e login de usuário.
- Atualização de perfil, incluindo upload de foto.
- Adicionar, editar e excluir despesas.
- Filtrar e ordenar despesas por critérios definidos.

# Como executar o projeto  
## Frontend  
Pré-requisitos: Node.js e ambiente React Native configurado e emulador android instalado

```bash
# clonar repositório
git clone https://github.com/MatheusWDB/anota-ai.git

# entrar na pasta do projeto frontend
cd anota-ai/frontend

# instalar dependências
npm install

# executar o projeto
npm run android
```

## Backend
Pré-requisitos: Node.js instalado e configurar informações do banco de dados

```bash
# clonar repositório
git clone https://github.com/MatheusWDB/anota-ai.git

# entrar na pasta do projeto backend
cd anota-ai/backend

# instalar dependências
npm install

# executar o projeto
npm run dev
```
